# Runtime and delivery concepts

- [Native Editor](./native-editor.md): A product responsibility that provides WAML editing in native and web-delivered forms.
- [Command-Line Tool](./command-line-tool.md): A product responsibility that validates, formats, queries, and changes a bundle without a user interface.
- [Language Server](./language-server.md): A responsibility that reports bundle diagnostics to a text editor while the author types.
- [Text Editor Integration](./text-editor-integration.md): An extension that starts the language server for Markdown documents in a general text editor.
- [Local Bundle](./local-bundle.md): A locally stored form of an OKF Bundle.
- [Share Link](./share-link.md): A link whose address fragment contains a full OKF Bundle.
- [Browser](./browser.md): The execution environment for the web-delivered native editor.
- [WASM Web Artifact](./wasm-web-artifact.md): A static web-delivery artifact for the native editor.
- [GitHub Pages](./github-pages.md): A publication responsibility that makes the static web artifact available.
- [Native Web Delivery](./native-web-delivery.md): The responsibility that publishes the native editor for browser delivery.
