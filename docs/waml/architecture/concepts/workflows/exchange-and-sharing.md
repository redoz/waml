# Exchange and Sharing

## Relationships
- depends [OKF Bundle](../model/okf-bundle.md)

## Notes
- Imports supported content with a merge or replace preview.
- Exports the current visual model as SVG and produces PNG for copying or saving.
- Shares the complete bundle in a URL fragment that a recipient can open.
