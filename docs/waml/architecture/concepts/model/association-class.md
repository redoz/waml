# Association Class

## Relationships
- specializes [Classifier](./classifier.md)

## Notes
- Use an association class when the connection has its own features. The two connected elements then keep their own features.
- The connection keeps its direct link to the far element. The reader can go from one element to the other element without a step through the association class.
- The name of the connection gives access to the association class. The connection does not go through an intermediate element.
