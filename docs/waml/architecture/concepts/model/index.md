# Model concepts

* [OKF Bundle](./okf-bundle.md) - A hierarchical collection of Markdown documents exchanged as one bundle.
* [Authored Document](./authored-document.md) - A human-maintained document that contributes authored WAML content.
* [WAML Model](./waml-model.md) - A resolved semantic model derived from an OKF Bundle.
* [Model Element](./model-element.md) - An abstract resolved item within a WAML Model.
* [Classifier](./classifier.md) - A Model Element that names a type or category in the model.
* [Relationship](./relationship.md) - A Model Element that expresses a connection between model elements.
* [Diagram](./diagram.md) - A curated structural view of a WAML Model.
* [Behavioral View](./behavioral-view.md) - A curated view that presents behavior from a WAML Model.
* [Diagnostic](./diagnostic.md) - A record that identifies a problem in authored content.
