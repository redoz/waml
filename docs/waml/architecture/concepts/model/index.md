# Model concepts

* [OKF Bundle](./okf-bundle.md) - A hierarchical collection of Markdown documents exchanged as one bundle.
* [Authored Document](./authored-document.md) - A human-maintained document that contributes authored WAML content.
* [Index Document](./index-document.md) - A navigation document that lists the direct contents of one bundle directory.
* [WAML Model](./waml-model.md) - A resolved semantic model derived from an OKF Bundle.
* [Model Element](./model-element.md) - An abstract resolved item within a WAML Model.
* [Classifier](./classifier.md) - A Model Element that names a type or category in the model.
* [Relationship](./relationship.md) - A Model Element that expresses a connection between model elements.
* [Association Class](./association-class.md) - A Classifier that carries the features of a named connection between two elements.
* [Package](./package.md) - A Model Element that groups other elements for containment and disclosure.
* [Note](./note.md) - A Model Element that annotates other elements without changing what they mean.
* [Stereotype](./stereotype.md) - An open-ended label that adds domain meaning to a model element without adding a new kind of element.
* [Diagram](./diagram.md) - A curated structural view of a WAML Model.
* [Behavioral View](./behavioral-view.md) - A curated view that presents behavior from a WAML Model.
* [Profile](./profile.md) - A presentation lens a Diagram selects to decide what its members emphasize.
* [Layout Constraint](./layout-constraint.md) - An authored statement of how a Diagram's members sit relative to one another.
* [View Geometry](./view-geometry.md) - The solved positions, group shapes, and connection routes a view is drawn from.
* [Diagnostic](./diagnostic.md) - A record that identifies a problem in authored content.
