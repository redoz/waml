# Export a Bundle

**Goal:** A reader takes the content out again — as files, or as something to
paste elsewhere.

**Why:** A format nobody can leave is a trap. Exportability is what makes
adopting WAML a low-risk decision.

**Done when:** A bundle opened from a link can be written back out as the same
files it came from, and a diagram can be exported as an image.

**Status:** partial — unverified
**MVP:** no

## Notes

- Bundle export exists in the editor and loads exported bundles back.
- Image export does not exist. It is the single most-requested thing of any
  diagram tool and is the obvious first non-MVP feature.
- `MVP: no`: the dogfood bar is reading and authoring, not extraction.
