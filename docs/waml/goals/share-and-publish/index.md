# Share and Publish

A reader opens a bundle with no installation and no account.

* [Share a Link](./share-a-link.md) - A bundle becomes a link that makes it again in a browser.
* [Run in a Browser](./run-in-a-browser.md) - The same editor operates as a web artifact.
* [Serve Locally](./serve-locally.md) - One command serves the editor against a local directory.
* [Publish a Site](./publish-a-site.md) - Each push to the main branch publishes the artifact again.
* [Export a Bundle](./export-a-bundle.md) - A reader takes the content out again.
