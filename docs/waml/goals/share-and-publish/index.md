# Share and Publish

A reader opens a bundle with no installation and no account.

* [Share a Link](./share-a-link.md) - A bundle packs into a link that rebuilds it in a browser.
* [Run in a Browser](./run-in-a-browser.md) - The same editor runs as a web artifact with the same views.
* [Publish a Site](./publish-a-site.md) - Every push to main republishes the artifact.
* [Export a Bundle](./export-a-bundle.md) - A reader takes the content out again.
