# Browse the Tree

**Goal:** A reader sees the structure of the bundle and opens documents from
it.

**Why:** A bundle is a forest of packages. Without a tree, a reader finds only
the documents that another document links to.

**Done when:** The tree shows each document and each package in the bundle. A
single click opens the shared preview tab. A double click makes that tab
permanent. The reader can hide the tree.

**Status:** done — unverified
**MVP:** yes

## Notes

- A double click on an open preview tab makes that tab permanent in its
  position. The editor does not make a second tab. The editor does not change a
  permanent tab back to a preview tab.
- A narrow window puts the tree above the view. A wide window puts the tree at
  the side. Refer to [Fit the Window](./fit-the-window.md).
- The tree has no search function and no filter. This bundle is small, thus the
  bar does not need them. Examine this again when a bundle becomes larger than
  one screen.
