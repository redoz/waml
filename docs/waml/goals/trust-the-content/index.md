# Trust the Content

The bundle on disk stays correct, and the tool reports each problem.

* [Round-Trip Losslessly](./round-trip-losslessly.md) - Bytes that the author did not change come back unchanged.
* [Report Every Problem](./report-every-problem.md) - Diagnostics from each layer come to the reader at each surface.
* [Resolve References](./resolve-references.md) - A link resolves, or the tool reports it.
* [Format Canonically](./format-canonically.md) - The tool writes the same bytes for the same model each time.
* [Keep Indexes Correct](./keep-indexes-correct.md) - Each directory index agrees with its package.
