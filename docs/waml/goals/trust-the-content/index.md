# Trust the Content

The bundle on disk survives every round trip, and every problem is reported.

* [Round-Trip Losslessly](./round-trip-losslessly.md) - Bytes the author wrote and did not touch come back unchanged.
* [Report Every Problem](./report-every-problem.md) - Diagnostics from every layer reach the reader at every surface.
* [Resolve References](./resolve-references.md) - A link to a document or an element either resolves or is reported.
* [Format Canonically](./format-canonically.md) - Serialization is deterministic, so a diff shows only what changed.
* [Keep Indexes Correct](./keep-indexes-correct.md) - Every directory index matches the package it describes.
