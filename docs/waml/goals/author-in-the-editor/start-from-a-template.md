# Start from a Template

**Goal:** An author starts a package from an empty package, a blank diagram, or
a complete example.

**Why:** A valid example gives a new author a safe starting point.

**Done when:** The package flow offers the three tiers, creates editable source,
and produces content that validates and draws without another edit.

**Status:** partial
**MVP:** no

## Planned behavior

The three-tier template list and complete per-diagram examples have no passing
acceptance scenario in the frozen inventory.

## Notes

- The current empty-package path is not evidence for the complete list.
- A template must be repository content so format changes produce test
  failures.
- Each complete example must remain small and cover the supported feature cut
  for its diagram kind.
