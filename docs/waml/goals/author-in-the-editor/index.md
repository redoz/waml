# Author in the Editor

An author changes a bundle in the editor.

* [Create and Delete Documents](./create-and-delete-documents.md) - An author adds, renames, moves, and removes documents and packages.
* [Start from a Template](./start-from-a-template.md) - A new package starts from an empty tier or from an example.
* [Edit Prose](./edit-prose.md) - An author writes the Markdown body of a document.
* [Edit the Model](./edit-the-model.md) - An author changes typed structure with the inspector and the diagram.
* [Draw on the Canvas](./draw-on-the-canvas.md) - An author makes a diagram with direct manipulation.
* [Author with the Keyboard](./author-with-the-keyboard.md) - An author makes a full diagram with the keyboard only.
* [Arrange a Diagram](./arrange-a-diagram.md) - An author overrides the solver where the solver is incorrect.
* [Reduce the Effort](./reduce-the-effort.md) - Each frequent task has a measured, small number of actions.
* [Save and Undo](./save-and-undo.md) - An author does not lose work and can go back one step.
