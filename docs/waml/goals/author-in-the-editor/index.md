# Author in the Editor

An author changes a bundle without leaving the editor.

* [Create and Delete Documents](./create-and-delete-documents.md) - An author adds, renames, moves, and removes documents and packages.
* [Edit Prose](./edit-prose.md) - An author writes the Markdown body of a document in the editor.
* [Edit the Model](./edit-the-model.md) - An author changes typed structure through the inspector and the diagram.
* [Arrange a Diagram](./arrange-a-diagram.md) - An author overrides the solver where the solver is wrong.
* [Save and Undo](./save-and-undo.md) - An author never loses work and can always step back.
