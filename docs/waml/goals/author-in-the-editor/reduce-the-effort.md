# Reduce the Effort

**Goal:** Common authoring tasks cost a known, small number of actions, and
that number is measured rather than assumed.

**Why:** "Easy" is not a status anyone can mark `done`. Without a number,
authoring ergonomics stays a matter of opinion and never gets prioritised
against features that have visible bugs.

**Done when:** A named budget exists for each common task, the current cost is
measured against it, and no budget is exceeded. Starting set:

| Task | Budget |
| --- | --- |
| Add a class with a title | 2 actions |
| Add an attribute to a selected class | 2 actions |
| Connect two visible classes with a chosen relationship kind | 3 actions |
| Change a relationship's kind | 2 actions |
| Rename any element | 2 actions |
| Add a note to an element | 3 actions |

An action is a click, a drag, or a keystroke sequence that completes one intent
— not an individual key press.

**Status:** planned — unverified
**MVP:** no

## Notes

- The budgets above are a first proposal, not a measurement. The first piece of
  work here is counting what these cost today; several are likely far over.
- Measurement is the deliverable. A budget nobody checks decays into a comment.
- `MVP: no`, but this is what turns [Draw on the
  Canvas](./draw-on-the-canvas.md) and [Author with the
  Keyboard](./author-with-the-keyboard.md) from opinions into finishable work.
