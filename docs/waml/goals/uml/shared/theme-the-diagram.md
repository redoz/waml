# Theme the Diagram

**Goal:** Each diagram remains legible in light and dark themes at every
supported zoom.

**Why:** A diagram must remain usable when a reader changes the system theme.

**Done when:** Each diagram is legible in both themes, keeps distinct kind
accents, and redraws without a frame from the previous theme.

**Status:** planned
**MVP:** no

## Notes

- The frozen inventory has no shipped diagram-theme scenario for this goal.
- Light is the reference theme. A future shipped contract must also cover dark
  theme and zoom behavior.
