# Product Actors

- [Author](./author.md) - Changes WAML content.
- [Reader](./reader.md) - Opens and reads WAML content.
- [Command-Line User](./command-line-user.md) - Starts WAML commands.
- [Automation Client](./automation-client.md) - Starts WAML commands in an automated process.
- [Language Client](./language-client.md) - Requests WAML language features.
