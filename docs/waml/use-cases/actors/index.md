# Product Actors

* [Author](./author.md) - A person who changes WAML content.
* [Reader](./reader.md) - A person who opens and reads WAML content.
* [Command-Line User](./command-line-user.md) - A person who starts WAML commands from a shell.
* [Automation Client](./automation-client.md) - An external process that starts WAML commands or publication work.
* [Language Client](./language-client.md) - An external text editor that requests WAML language features.
