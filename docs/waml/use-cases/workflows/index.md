# Product Workflows

## Editor workflows

* [Browse the Tree](./browse-the-tree.md) - A reader navigates bundle content in the project tree.
* [Edit Prose](./edit-prose.md) - An author changes the Markdown body of a WAML document.
* [Fit the Window](./fit-the-window.md) - A product user keeps editor controls usable at different widths.
* [Interact with an Activity Diagram](./interact-with-an-activity-diagram.md) - A reader views and interacts with an activity flow.
* [Interact with a Class Diagram](./interact-with-a-class-diagram.md) - A product user views and changes a class diagram.
* [Interact with a Sequence Diagram](./interact-with-a-sequence-diagram.md) - A reader views and interacts with a sequence diagram.
* [Navigate and Return](./navigate-and-return.md) - A reader follows the current path and returns to earlier positions.
* [Open a Bundle](./open-a-bundle.md) - A reader opens a WAML bundle in the product.
* [Read a Document](./read-a-document.md) - A reader views a Markdown document as formatted content.
* [Report Every Problem](./report-every-problem.md) - An author receives diagnostics and status results for current content.
* [Route the Edges](./route-the-edges.md) - A reader sees class relations that keep their group constraints.
* [Save and Undo](./save-and-undo.md) - An author saves work and moves through edit history.
* [Select and Inspect](./select-and-inspect.md) - A product user selects a diagram subject and inspects it.
* [Sequence Language](./sequence-language.md) - An author defines sequence behavior with the WAML sequence language.
* [Solve the Layout](./solve-the-layout.md) - A reader receives a usable diagram layout or a readable conflict.
* [Use the Shell](./use-the-shell.md) - A reader controls docks and the document shell.
* [Work with Tabs](./work-with-tabs.md) - A reader uses preview and permanent document tabs.
* [Export a Bundle](./export-a-bundle.md) - A reader takes WAML content out of the product.
* [Publish a Site](./publish-a-site.md) - Automation publishes a complete WAML web artifact.
* [Run in a Browser](./run-in-a-browser.md) - A reader uses the WAML editor as a web artifact.
* [Serve Locally](./serve-locally.md) - A command-line user serves a local bundle to a reader.
* [Share a Link](./share-a-link.md) - A command-line user makes a bundle link for a reader.
* [Command-Line Tool](./command-line-tool.md) - A caller validates, formats, queries, and changes a WAML bundle.
* [Language Server](./language-server.md) - A language client requests WAML language features.
* [Text Editor Integration](./text-editor-integration.md) - An author uses WAML language features in an integrated text editor.
